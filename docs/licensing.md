## Источники данных и сервисы

Лицензия программы автоматически не распространяется на данные, получаемые от внешних сервисов. Перед публичным запуском для каждого источника необходимо зафиксировать правила доступа, повторного использования, кэширования, атрибуции и ограничения частоты запросов.

| Источник | Назначение | Что проверить |
|---|---|---|
| HamQSL XML | Солнечные и геомагнитные показатели, оценки диапазонов, MUF фиксированных точек | Условия использования XML, атрибуцию, частоту запросов и правила кэширования |
| NOAA SWPC | Космическая погода, D-RAP, GloTEC и другие продукты | Условия конкретного продукта, указание источника, ограничения на перераспространение |
| GIRO / KC2G | Данные ионозондов, foF2 и MUF-карты | Условия API/набора данных, атрибуцию, разрешение на кэширование и публикацию производных данных |
| PSK Reporter | Наблюдения приёма радиостанций | Условия MQTT/API, допустимую частоту и объём сбора, хранение и повторную публикацию |\n| Яндекс Карты JavaScript API и Геокодер | Поиск адресов и географические названия Maidenhead-локаторов | API-ключ, доменные ограничения, отдельные суточные квоты, обязательное отображение результатов геокодирования через JavaScript API Яндекс Карт |

## Правила проекта

1. Не включай код или данные с неясными условиями распространения.
2. Для каждого стороннего программного компонента фиксируй URL проекта, точную версию, лицензию и локальные изменения.
3. Для каждого источника показывай источник и время измерения; время получения нашим сервером храни отдельно.
4. Не смешивай лицензию кода и условия использования данных.
5. Не выдавай модельные оценки за измерения и не скрывай формулы, коэффициенты или версии моделей.
6. Перед релизом формируй перечень прямых и транзитивных зависимостей с их лицензиями.
